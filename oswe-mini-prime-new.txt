## 🔧 Notes about implementation & behaviour (important points documented)

- Constructor stores the reference to the `funds` array directly — it does NOT clone it. If callers mutate the supplied array later, `FundService` sees those changes.
- `getFundById(id)` returns `Fund | undefined`. Callers must handle the `undefined` case.
- `filterByRisk(level)` accepts only `"Low" | "Medium" | "High"` (enforced by TypeScript). Matching is strict equality.
- `calculateAverageNav()` returns `0` when there are no funds (explicit behavior in code). No rounding is applied; invalid `nav` values (NaN/Infinity) will produce NaN/Infinity results — callers should validate inputs.
